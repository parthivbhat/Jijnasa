# 🕉️ Jijnasa

> **A personal technology intelligence and learning agent.**

Jijnasa is a personal AI-powered technology intelligence and learning agent built to help me **discover, understand, learn, remember, and share technology knowledge**.

It combines:

- 📰 Technology news collection
- 🤖 AI-powered news analysis
- 🧠 Personal learning
- 🗂️ Obsidian knowledge management
- ✍️ X content generation
- ⏰ Automated daily news processing
- 🔀 Multiple LLM providers with fallback support

The goal is to turn information into useful personal knowledge instead of simply consuming endless technology news.
